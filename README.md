# claude-Utube

Xưởng phim cho Claude:
- **Học phong cách** của một kênh YouTube bằng cách đo từng khung hình, rồi lưu thành phong cách dùng lại được.
- **Làm phim bằng code** theo phong cách đã học, hoặc theo các phong cách có sẵn trong thư viện.

Dự án được xây theo quy trình [GitHub Spec Kit](https://github.com/github/spec-kit).

## Cách làm việc
Mở Claude Code trong thư mục này. Xem `CLAUDE.md` để biết các luồng làm việc và 3 mức quy trình (Trực tiếp, Nhẹ, Đầy đủ).
